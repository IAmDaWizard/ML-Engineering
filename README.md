# ML-Engineering

Repository with machine learning engineering practice tasks and Jupyter Notebook experiments.

## About

This repository contains practical ML Engineering labs and experiments. The project is focused on working with data, notebooks, basic machine learning workflows and analysis.

## Repository structure

```text
ML-Engineering/
├── Lab2/
├── Lab3/
├── Untitled.ipynb
├── .gitignore
└── README.md
```

## Technologies

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Scikit-learn

## Topics covered

- Data analysis
- Notebook-based experiments
- Basic machine learning pipeline
- Model training and evaluation
- Working with datasets

## How to run

Clone the repository:

```bash
git clone https://github.com/IAmDaWizard/ML-Engineering.git
cd ML-Engineering
```

Install dependencies if needed:

```bash
pip install numpy pandas scikit-learn jupyter
```

Run Jupyter Notebook:

```bash
jupyter notebook
```
